## 1. 项目概述

### 1.1 项目背景

Myblog是一个基于Spring Boot和Vue3的现代化个人博客系统，需要构建完整的后端服务来支撑前端功能。

### 1.2 项目目标

- 构建RESTful API服务
- 实现完整的博客功能
- 保证系统性能和安全性
- 提供良好的可维护性和扩展性

### 1.3 功能范围

- 用户认证与权限管理
- 文章内容管理
- 评论互动系统
- 数据分析统计
- 通知消息系统
- 文件上传管理

### 3.3 分层职责

| 层级 | 职责 | 规范 |
|------|------|------|

| **Service** | 业务逻辑、事务管理 | 可调用多个Mapper |
| **Mapper** | 数据访问、SQL执行 | 复杂SQL使用XML |
| **Entity** | 与数据库表对应 | 使用MyBatis-Flex注解 |
| **DTO** | 数据传输、接收参数 | 使用Validation注解 |
| **VO** | 返回给前端的数据 | 不包含敏感字段 |

#### 5.3.3 接口限流实现
```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface RateLimit {
    int perSecond() default 10;
    int perMinute() default 60;
    String message() default "请求过于频繁，请稍后再试";
}

@Aspect
@Component
@RequiredArgsConstructor
public class RateLimitAspect {
    
    private final StringRedisTemplate redisTemplate;
    
    @Around("@annotation(rateLimit)")
    public Object around(ProceedingJoinPoint point, RateLimit rateLimit) throws Throwable {
        HttpServletRequest request = ((ServletRequestAttributes) 
            RequestContextHolder.getRequestAttributes()).getRequest();
        String key = "rate_limit:" + request.getRequestURI() + ":" + getClientIp(request);
        
        // 检查限流
        Long count = redisTemplate.opsForValue().increment(key);
        if (count == 1) {
            redisTemplate.expire(key, 1, TimeUnit.MINUTES);
        }
        
        if (count > rateLimit.perMinute()) {
            throw new BusinessException(429, rateLimit.message());
        }
        
        return point.proceed();
    }
}
```

#### 5.3.4 评论嵌套查询
```java
// 使用递归CTE查询嵌套评论
public List<CommentVO> getCommentTree(Long articleId) {
    String sql = """
        WITH RECURSIVE comment_tree AS (
            SELECT c.*, u.username, u.avatar, u.nickname, 0 as level
            FROM t_comment c
            LEFT JOIN t_user u ON c.user_id = u.id
            WHERE c.article_id = ? AND c.parent_id = 0 AND c.is_deleted = 0
            UNION ALL
            SELECT c.*, u.username, u.avatar, u.nickname, ct.level + 1
            FROM t_comment c
            LEFT JOIN t_user u ON c.user_id = u.id
            INNER JOIN comment_tree ct ON c.parent_id = ct.id
            WHERE c.is_deleted = 0 AND ct.level < 2
        )
        SELECT * FROM comment_tree ORDER BY created_time DESC
        """;
    return Db.selectListBySql(sql, CommentVO.class, articleId);
}
```

#### 5.3.5 敏感词过滤（DFA算法）
```java
@Component
public class SensitiveWordFilter {
    
    private final Map<Character, Map> sensitiveWordMap = new HashMap<>();
    
    @PostConstruct
    public void init() {
        // 加载敏感词库
        List<SensitiveWord> words = sensitiveWordMapper.selectAll();
        for (SensitiveWord word : words) {
            addWord(word.getWord());
        }
    }
    
    private void addWord(String word) {
        Map<Character, Map> currentMap = sensitiveWordMap;
        for (char c : word.toCharArray()) {
            currentMap = currentMap.computeIfAbsent(c, k -> new HashMap<>());
        }
        currentMap.put('end', new HashMap<>());
    }
    
    public String filter(String text) {
        StringBuilder result = new StringBuilder();
        for (int i = 0; i < text.length(); i++) {
            int matchLength = checkWord(text, i);
            if (matchLength > 0) {
                result.append("***");
                i += matchLength - 1;
            } else {
                result.append(text.charAt(i));
            }
        }
        return result.toString();
    }
    
    private int checkWord(String text, int start) {
        Map<Character, Map> currentMap = sensitiveWordMap;
        int length = 0;
        for (int i = start; i < text.length(); i++) {
            char c = text.charAt(i);
            currentMap = currentMap.get(c);
            if (currentMap == null) break;
            length++;
            if (currentMap.containsKey('end')) return length;
        }
        return 0;
    }
}
```

@ExtendWith(MockitoExtension.class)
class UserServiceTest {
    
    @Mock
    private UserMapper userMapper;
    
    @InjectMocks
    private UserService userService;
    
    @Test
    @DisplayName("用户注册成功")
    void registerSuccess() {
        // Given
        UserRegisterDTO dto = new UserRegisterDTO();
        dto.setUsername("testuser");
        dto.setPassword("Test123@");
        dto.setEmail("test@example.com");
        
        when(userMapper.selectCount(any())).thenReturn(0L);
        when(userMapper.insert(any())).thenReturn(1);
        
        // When
        UserVO result = userService.register(dto);
        
        // Then
        assertThat(result).isNotNull();
        assertThat(result.getUsername()).isEqualTo("testuser");
        verify(userMapper).insert(any(User.class));
    }
    
    @Test
    @DisplayName("用户名已存在，注册失败")
    void registerUsernameExists() {
        // Given
        UserRegisterDTO dto = new UserRegisterDTO();
        dto.setUsername("existing");
        dto.setPassword("Test123@");
        
        when(userMapper.selectCount(any())).thenReturn(1L);
        
        // When & Then
        assertThatThrownBy(() -> userService.register(dto))
            .isInstanceOf(BusinessException.class)
            .hasMessage("用户名已存在");
    }
}

### 7.3 部署脚本

**deploy.sh**
```bash
#!/bin/bash

# 配置
APP_NAME=myblog
APP_VERSION=1.0.0
APP_PORT=8080

# 停止旧服务
echo "停止旧服务..."
pid=$(ps -ef | grep $APP_NAME | grep -v grep | awk '{print $2}')
if [ -n "$pid" ]; then
    kill -9 $pid
fi

# 备份旧版本
echo "备份旧版本..."
if [ -f "$APP_NAME-$APP_VERSION.jar" ]; then
    mv $APP_NAME-$APP_VERSION.jar backup/$APP_NAME-$APP_VERSION-$(date +%Y%m%d%H%M%S).jar
fi

# 部署新版本
echo "部署新版本..."
cp target/$APP_NAME-$APP_VERSION.jar .

# 启动服务
echo "启动服务..."
nohup java -jar $APP_NAME-$APP_VERSION.jar \
    --spring.profiles.active=prod \
    > logs/$APP_NAME.log 2>&1 &

# 健康检查
echo "健康检查..."
sleep 10
if curl -s http://localhost:$APP_PORT/api/health | grep -q "UP"; then
    echo "部署成功！"
else
    echo "部署失败，请检查日志"
    exit 1
fi
```
