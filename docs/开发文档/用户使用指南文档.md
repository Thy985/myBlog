# 个人博客系统用户使用指南

## 1. 系统概述

个人博客系统是一个面向专业人士和企业的高级博客平台，支持丰富的内容创作、管理和展示功能，具备企业级的安全性、可扩展性和性能表现。本指南将帮助您了解系统的使用方法，包括注册登录、核心功能操作、常见问题解决等内容。

## 2. 用户角色

系统包含三种用户角色，每种角色具有不同的权限和功能：

### 2.1 管理员
- **权限**：拥有所有内容的发布、编辑、删除权限，拥有所有用户的管理权限，拥有系统设置和配置权限，拥有所有数据分析和统计权限
- **适用场景**：网站所有者、系统管理员

### 2.2 普通用户
- **权限**：可管理自己发布的文章、分类标签、媒体库，可浏览所有文章，可对管理员发布的文章进行评论，可对所有文章进行点赞，可查看自己的个人资料和管理自己的账号设置
- **适用场景**：注册用户、内容创作者

### 2.3 未登录访客
- **权限**：仅具备浏览管理员发布的文章和点赞权限，不可访问评论功能，不可管理任何内容
- **适用场景**：网站访客、潜在用户

## 3. 注册与登录

### 3.1 注册流程

1. **访问注册页面**
   - 在网站首页点击「注册」按钮，或直接访问 `/register` 路径

2. **填写注册信息**
   - 输入用户名（建议使用字母、数字组合，长度4-20位）
   - 设置密码（建议包含字母、数字和特殊字符，长度8-20位）
   - 输入邮箱地址（用于验证和找回密码）
   - 输入手机号（可选，用于验证和找回密码）
   - 获取并输入验证码
   - 阅读并同意用户协议和隐私政策

3. **完成注册**
   - 点击「注册」按钮，系统会发送验证邮件到您的邮箱
   - 登录邮箱，点击验证链接完成注册
   - 注册成功后，系统会自动登录并跳转到首页

### 3.2 登录流程

1. **访问登录页面**
   - 在网站首页点击「登录」按钮，或直接访问 `/login` 路径

2. **选择登录方式**
   - **账号密码登录**：输入用户名和密码
   - **邮箱登录**：输入邮箱和密码
   - **手机号登录**：输入手机号，获取并输入验证码

3. **完成登录**
   - 点击「登录」按钮，系统验证通过后会跳转到首页
   - 登录成功后，系统会在浏览器中存储登录状态，下次访问时自动登录

### 3.3 忘记密码

1. **访问找回密码页面**
   - 在登录页面点击「忘记密码」链接

2. **选择找回方式**
   - **邮箱找回**：输入注册邮箱，获取并输入验证码，设置新密码
   - **手机号找回**：输入注册手机号，获取并输入验证码，设置新密码

3. **重置密码**
   - 点击「确定」按钮，密码重置成功后可以使用新密码登录

## 4. 管理员功能操作指南

### 4.1 后台管理入口
- 登录后，在网站顶部导航栏点击「管理后台」进入管理员控制台
- 或直接访问 `/admin` 路径

### 4.2 内容管理

#### 4.2.1 文章管理
1. **发布文章**
   - 在后台左侧菜单点击「文章管理」→「发布文章」
   - 填写文章标题、描述、选择分类和标签
   - 使用Markdown编辑器编写文章内容
   - 上传文章封面图片
   - 设置文章状态（草稿/已发布）
   - 点击「发布」按钮完成发布

2. **编辑文章**
   - 在后台左侧菜单点击「文章管理」→「文章列表」
   - 找到需要编辑的文章，点击「编辑」按钮
   - 修改文章内容，点击「更新」按钮保存修改

3. **删除文章**
   - 在后台左侧菜单点击「文章管理」→「文章列表」
   - 找到需要删除的文章，点击「删除」按钮
   - 确认删除操作

4. **文章草稿**
   - 在编辑文章时，系统会自动保存草稿
   - 在文章列表页面可以查看和管理草稿

#### 4.2.2 分类管理
1. **创建分类**
   - 在后台左侧菜单点击「分类管理」→「添加分类」
   - 填写分类名称
   - 选择父分类（可选，用于创建多级分类）
   - 设置排序权重
   - 点击「保存」按钮

2. **编辑分类**
   - 在后台左侧菜单点击「分类管理」→「分类列表」
   - 找到需要编辑的分类，点击「编辑」按钮
   - 修改分类信息，点击「保存」按钮

3. **删除分类**
   - 在后台左侧菜单点击「分类管理」→「分类列表」
   - 找到需要删除的分类，点击「删除」按钮
   - 确认删除操作

#### 4.2.3 标签管理
1. **创建标签**
   - 在后台左侧菜单点击「标签管理」→「添加标签」
   - 填写标签名称
   - 设置排序权重
   - 点击「保存」按钮

2. **编辑标签**
   - 在后台左侧菜单点击「标签管理」→「标签列表」
   - 找到需要编辑的标签，点击「编辑」按钮
   - 修改标签信息，点击「保存」按钮

3. **删除标签**
   - 在后台左侧菜单点击「标签管理」→「标签列表」
   - 找到需要删除的标签，点击「删除」按钮
   - 确认删除操作

#### 4.2.4 媒体库管理
1. **上传文件**
   - 在后台左侧菜单点击「媒体库」→「上传文件」
   - 点击上传区域，选择需要上传的文件
   - 支持批量上传和拖拽上传
   - 上传完成后，系统会生成文件访问URL

2. **管理文件**
   - 在后台左侧菜单点击「媒体库」→「文件列表」
   - 可以查看、编辑、删除已上传的文件
   - 支持按文件类型、上传时间等条件筛选

### 4.3 用户管理

1. **查看用户列表**
   - 在后台左侧菜单点击「用户管理」→「用户列表」
   - 可以查看所有注册用户的信息

2. **编辑用户**
   - 在用户列表页面，找到需要编辑的用户，点击「编辑」按钮
   - 修改用户信息和权限
   - 点击「保存」按钮

3. **删除用户**
   - 在用户列表页面，找到需要删除的用户，点击「删除」按钮
   - 确认删除操作

4. **设置用户角色**
   - 在编辑用户页面，可以设置用户的角色（管理员/普通用户）

### 4.4 系统设置

#### 4.4.1 站点设置
1. **基本信息**
   - 在后台左侧菜单点击「系统设置」→「站点设置」
   - 填写网站名称、作者、简介、联系方式等信息
   - 上传网站Logo和作者头像
   - 点击「保存」按钮

2. **SEO配置**
   - 在站点设置页面，填写SEO标题、关键词、描述
   - 点击「保存」按钮

3. **主题设置**
   - 在站点设置页面，选择网站主题和颜色方案
   - 点击「保存」按钮

#### 4.4.2 插件管理
1. **安装插件**
   - 在后台左侧菜单点击「系统设置」→「插件管理」
   - 点击「安装插件」按钮
   - 上传插件包或选择在线插件
   - 点击「安装」按钮

2. **启用/禁用插件**
   - 在插件列表页面，找到需要操作的插件
   - 点击「启用」或「禁用」按钮

3. **配置插件**
   - 在插件列表页面，找到需要配置的插件，点击「配置」按钮
   - 修改插件配置，点击「保存」按钮

4. **卸载插件**
   - 在插件列表页面，找到需要卸载的插件，点击「卸载」按钮
   - 确认卸载操作

#### 4.4.3 数据备份
1. **手动备份**
   - 在后台左侧菜单点击「系统设置」→「数据备份」
   - 选择备份类型（数据库/文件/完整）
   - 点击「开始备份」按钮
   - 备份完成后，可以下载备份文件

2. **自动备份设置**
   - 在数据备份页面，设置自动备份频率和保留天数
   - 点击「保存」按钮

3. **恢复数据**
   - 在数据备份页面，找到需要恢复的备份文件
   - 点击「恢复」按钮
   - 确认恢复操作

#### 4.4.4 日志管理
1. **查看操作日志**
   - 在后台左侧菜单点击「系统设置」→「日志管理」→「操作日志」
   - 可以查看所有用户的操作记录
   - 支持按用户、时间、操作类型等条件筛选

2. **查看访问日志**
   - 在后台左侧菜单点击「系统设置」→「日志管理」→「访问日志」
   - 可以查看网站的访问记录
   - 支持按IP、时间、访问路径等条件筛选

3. **查看错误日志**
   - 在后台左侧菜单点击「系统设置」→「日志管理」→「错误日志」
   - 可以查看系统运行过程中产生的错误
   - 支持按时间、错误类型等条件筛选

### 4.5 数据分析

1. **访问统计**
   - 在后台左侧菜单点击「数据分析」→「访问统计」
   - 可以查看网站的PV、UV、停留时间、来源分析等数据
   - 支持按时间段查看

2. **内容分析**
   - 在后台左侧菜单点击「数据分析」→「内容分析」
   - 可以查看热门文章、阅读趋势、用户偏好等数据
   - 支持按时间段查看

3. **用户分析**
   - 在后台左侧菜单点击「数据分析」→「用户分析」
   - 可以查看用户画像、活跃度、互动情况等数据
   - 支持按时间段查看

4. **转化分析**
   - 在后台左侧菜单点击「数据分析」→「转化分析」
   - 可以查看分享效果等数据
   - 支持按时间段查看

## 5. 普通用户功能操作指南

### 5.1 个人中心入口
- 登录后，在网站顶部导航栏点击「个人中心」进入用户控制台
- 或直接访问 `/user` 路径

### 5.2 内容管理

#### 5.2.1 发布文章
1. **进入发布页面**
   - 在个人中心点击「发布文章」按钮
   - 或在网站顶部导航栏点击「发布」按钮

2. **编写文章**
   - 填写文章标题、描述、选择分类和标签
   - 使用Markdown编辑器编写文章内容
   - 上传文章封面图片
   - 设置文章状态（草稿/已发布）
   - 点击「发布」按钮完成发布

3. **管理自己的文章**
   - 在个人中心点击「我的文章」查看自己发布的文章
   - 可以编辑、删除自己的文章

#### 5.2.2 管理个人分类标签
1. **创建分类**
   - 在个人中心点击「我的分类」→「添加分类」
   - 填写分类名称
   - 点击「保存」按钮

2. **创建标签**
   - 在个人中心点击「我的标签」→「添加标签」
   - 填写标签名称
   - 点击「保存」按钮

3. **管理分类标签**
   - 在个人中心可以查看、编辑、删除自己创建的分类和标签

#### 5.2.3 管理个人媒体库
1. **上传文件**
   - 在个人中心点击「我的媒体库」→「上传文件」
   - 点击上传区域，选择需要上传的文件
   - 上传完成后，可以在发布文章时使用

2. **管理文件**
   - 在个人中心点击「我的媒体库」查看自己上传的文件
   - 可以编辑、删除自己上传的文件

### 5.3 互动功能

#### 5.3.1 评论文章
1. **查看评论**
   - 在文章详情页面，滚动到页面底部查看评论

2. **发表评论**
   - 在文章详情页面，在评论输入框中输入评论内容
   - 点击「发表评论」按钮
   - 注意：普通用户只能对管理员发布的文章进行评论

3. **回复评论**
   - 在评论列表中，找到需要回复的评论，点击「回复」按钮
   - 输入回复内容，点击「发表回复」按钮

#### 5.3.2 点赞收藏
1. **点赞文章**
   - 在文章详情页面，点击文章标题下方的「点赞」按钮
   - 或在文章列表页面，点击文章卡片上的「点赞」按钮

2. **收藏文章**
   - 在文章详情页面，点击文章标题下方的「收藏」按钮
   - 收藏成功后，可以在个人中心的「我的收藏」中查看

#### 5.3.3 分享文章
1. **分享文章**
   - 在文章详情页面，点击文章标题下方的「分享」按钮
   - 选择分享平台（微信、微博、QQ等）
   - 或复制分享链接

2. **生成二维码**
   - 在分享弹窗中，可以查看文章的二维码
   - 其他用户扫描二维码可以直接访问文章

### 5.4 个人资料管理

1. **编辑个人资料**
   - 在个人中心点击「个人资料」→「编辑资料」
   - 修改昵称、头像、简介、联系方式等信息
   - 点击「保存」按钮

2. **修改密码**
   - 在个人中心点击「账户设置」→「修改密码」
   - 输入原密码和新密码
   - 点击「保存」按钮

3. **查看登录历史**
   - 在个人中心点击「账户设置」→「登录历史」
   - 可以查看最近的登录记录

## 7. 常见问题与解决方案

### 7.1 登录问题

#### 7.1.1 无法登录
- **问题**：输入正确的账号密码但无法登录
- **解决方案**：
  1. 检查账号密码是否正确，注意区分大小写
  2. 检查网络连接是否正常
  3. 尝试使用忘记密码功能重置密码
  4. 联系管理员检查账号状态

#### 7.1.2 验证码不显示
- **问题**：注册或登录时验证码不显示
- **解决方案**：
  1. 点击验证码图片刷新
  2. 检查网络连接是否正常
  3. 尝试使用邮箱或手机号验证码

### 7.2 内容管理问题

#### 7.2.1 文章发布失败
- **问题**：点击发布按钮后，文章发布失败
- **解决方案**：
  1. 检查文章标题、内容是否为空
  2. 检查网络连接是否正常
  3. 检查图片上传是否成功
  4. 尝试保存为草稿后再发布

#### 7.2.2 图片上传失败
- **问题**：上传图片时失败
- **解决方案**：
  1. 检查图片大小是否超过限制（建议不超过10MB）
  2. 检查图片格式是否支持（支持jpg、png、gif等常见格式）
  3. 检查网络连接是否正常
  4. 尝试使用不同的浏览器

### 7.3 互动功能问题

#### 7.3.1 无法评论
- **问题**：无法发表评论
- **解决方案**：
  1. 检查是否已登录
  2. 检查是否对管理员发布的文章评论（普通用户只能评论管理员文章）
  3. 检查评论内容是否符合要求
  4. 检查网络连接是否正常

#### 7.3.2 点赞失败
- **问题**：点击点赞按钮后没有反应
- **解决方案**：
  1. 检查网络连接是否正常
  2. 尝试刷新页面后再次点赞
  3. 检查浏览器是否支持JavaScript

### 7.4 系统问题

#### 7.4.1 页面加载缓慢
- **问题**：网站页面加载缓慢
- **解决方案**：
  1. 检查网络连接是否正常
  2. 尝试清除浏览器缓存
  3. 尝试使用不同的浏览器
  4. 联系管理员检查服务器状态

#### 7.4.2 功能按钮无法点击
- **问题**：某些功能按钮无法点击
- **解决方案**：
  1. 检查是否已登录并拥有相应权限
  2. 尝试刷新页面
  3. 检查浏览器是否支持JavaScript
  4. 尝试使用不同的浏览器

## 8. 注意事项

### 8.1 账号安全
- 请妥善保管您的账号密码，不要与他人分享
- 定期修改密码，使用强密码（包含字母、数字和特殊字符）
- 不要在公共电脑上保存登录状态
- 如发现账号异常，请及时联系管理员

### 8.2 内容规范
- 发布的内容必须符合法律法规和道德规范
- 不得发布侵犯他人知识产权的内容
- 不得发布广告、垃圾信息等无关内容
- 管理员有权删除违规内容

### 8.3 系统使用
- 建议使用Chrome、Firefox、Safari、Edge等主流浏览器
- 确保浏览器支持JavaScript和Cookie
- 保持浏览器更新到最新版本
