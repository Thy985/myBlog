# 页面跳转指南

## 1. 概述

本文档详细描述了个人博客系统的页面跳转规则、导航流程和用户体验规范，帮助开发者理解系统的路由机制，确保用户在浏览过程中获得流畅、无障碍的体验。

## 2. 路由架构

### 2.1 路由模式

系统使用 **HTML5 History 模式**（`createWebHistory()`），URL中不包含`#`符号，提供更美观的URL格式。

### 2.2 路由结构

```
┌─────────────────────────────────────────────────────────────┐
│                        App.vue                              │
│                   (根组件/全局过渡动画)                       │
└───────────────────────┬─────────────────────────────────────┘
                        │
        ┌───────────────┼───────────────┐
        │               │               │
        ▼               ▼               ▼
┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│   前台页面    │ │   后台页面    │ │   公共页面    │
│  (Header +   │ │  (Admin布局) │ │ (Login等)    │
│   Content +  │ │              │ │              │
│   Footer)    │ │              │ │              │
└──────────────┘ └──────────────┘ └──────────────┘
```

### 2.3 页面分类

| 分类 | 路径前缀 | 布局组件 | 认证要求 |
|------|----------|----------|----------|
| 首页 | `/` | Header + Footer | 无 |
| 文章详情 | `/article/detail` | Header + Footer | 无 |
| 分类列表 | `/category*` | Header + Footer | 无 |
| 标签列表 | `/tag*` | Header + Footer | 无 |
| 归档页 | `/archive` | Header + Footer | 无 |
| 搜索页 | `/search` | Header + Footer | 无 |
| 用户中心 | `/user*` | Header + Footer | **需要登录** |
| 登录注册 | `/login`, `/register` | 独立页面 | 无 |
| 管理后台 | `/admin/*` | Admin布局 | **管理员** |

## 3. 页面跳转流程

### 3.1 正常访问流程

```
用户点击链接/输入URL
       ↓
  [beforeEach守卫]
       ↓
  ├─ 显示加载进度条(NProgress)
  ├─ 检查登录状态
  ├─ 检查权限(如需)
  └─ 动态导入Store
       ↓
  [路由匹配]
       ↓
  [懒加载组件]
       ↓
  [afterEach守卫]
       ↓
  ├─ 更新页面标题
  └─ 隐藏加载进度条
       ↓
  [页面渲染完成]
```

### 3.2 登录后跳转流程

```
用户提交登录表单
       ↓
  验证账号密码
       ↓
  ├─ 成功 → 保存Token → 获取用户信息
  │         ↓
  │    检查是否需要MFA
  │     ↓           ↓
  │   是:跳转到     否:
  │   /verify-mfa   ↓
  │             检查redirectUrl
  │                ↓
  │          有redirectUrl?
  │           ↓       ↓
  │          是       否
  │           ↓       ↓
  │      跳转到原    跳转到首页(/)
  │      目标页面
  │
  └─ 失败 → 显示错误提示
```

### 3.3 权限拦截流程

```
用户访问受保护页面
       ↓
  [beforeEach守卫检查]
       ↓
  是否需要认证?(meta.requiresAuth)
       ↓
  ┌────┴────┐
  是        否
  ↓         ↓
  已登录?   直接放行
   ↓
  ┌──┴──┐
  是    否
  ↓     ↓
 放行  保存当前URL到redirectUrl
            ↓
       跳转到/login或/admin/login
       显示"请先登录"提示
```

## 5. 特殊跳转场景

### 5.1 Token过期处理

```
API请求返回401
      ↓
清除本地存储的Token
      ↓
跳转到登录页
      ↓
保存当前页面路径到redirectUrl
      ↓
显示"请重新登录"提示
```

### 5.2 404页面处理

```
访问不存在的路径
      ↓
路由匹配通配符 /:pathMatch(.*)*
      ↓
显示404页面
      ↓
提供"返回首页"按钮
```

### 5.3 退出登录处理

```
用户点击"退出登录"
      ↓
显示确认弹窗
      ↓
确认后:
  - 清除Token和用户信息
  - 清除临时MFA数据
  - 跳转到首页
  - 显示"退出成功"提示
```

## 6. 加载状态与过渡

### 6.1 进度条

- 使用 **NProgress** 库显示顶部进度条
- `beforeEach` 守卫触发时开始 (`nprogress.start()`)
- `afterEach` 守卫触发时结束 (`nprogress.done()`)
- 出现错误时也会结束进度条

### 6.2 页面过渡动画

```css
/* 前台页面过渡 */
.fade-enter-active, .fade-leave-active {
  transition: opacity 0.3s ease, transform 0.3s ease;
}
.fade-enter-from, .fade-leave-to {
  opacity: 0;
  transform: translateY(10px);
}

/* 后台页面过渡 */
.fade-enter-active {
  transition: all 0.3s;
  transition-delay: 0.3s;
}
.fade-leave-active {
  transition: all 0.3s;
}
```

### 6.3 滚动行为

| 场景 | 行为 |
|------|------|
| 有保存的位置 | 恢复到保存位置 |
| URL包含hash | 平滑滚动到锚点 |
| 路径变化 | 滚动到页面顶部 |
| 同路径参数变化 | 保持当前位置 |

## 7. 错误处理

### 7.1 路由错误捕获

```javascript
router.onError((error) => {
  hidePageLoading()
  logger.error('路由导航错误:', error.message)
  showMessage('页面导航失败，请稍后重试', 'error')
})
```

### 7.2 Store初始化失败

```javascript
// 动态导入Store失败时的降级处理
if (to.path.startsWith('/admin')) {
  showMessage('系统错误，请稍后重试', 'error')
  next({ path: '/' })
} else {
  next() // 前台页面放行
}
```

## 8. 性能优化措施

### 8.1 路由懒加载

所有页面组件都使用动态导入进行懒加载：
```javascript
const Index = () => import('@/views/frontend/index.vue')
const AdminArticleList = () => import('@/views/admin/article-list.vue')
```

### 8.2 组件缓存

后台页面使用 `<keep-alive>` 缓存最多10个组件实例：
```vue
<keep-alive :max="10">
  <component :is="Component"></component>
</keep-alive>
```

### 8.3 动态导入

权限守卫中使用动态导入Store，避免初始化时的依赖问题：
```javascript
const { useAuthStore, useSettingsStore } = await import('@/stores')
```

## 9. 最佳实践建议

### 9.1 编程式导航

推荐使用 `useRouter()` 进行编程式导航：

```javascript
import { useRouter } from 'vue-router'

const router = useRouter()

// 基本跳转
router.push('/path')

// 带参数跳转
router.push({
  path: '/search',
  query: { keyword: 'xxx' }
})

// 替换当前历史记录（不可回退）
router.replace('/path')
```

### 9.2 导航守卫使用

在组件内使用路由守卫：

```javascript
onBeforeRouteLeave((to, from) => {
  // 离开前的确认逻辑
  if (hasUnsavedChanges.value) {
    return confirm('确定离开吗？未保存的内容将丢失')
  }
})
```

### 9.3 避免白屏的措施

1. **确保所有路由都有对应的组件**
2. **使用Suspense包裹异步组件**（可选增强）
3. **正确配置loading状态**
4. **添加错误边界组件**

## 10. 常见问题排查

### 10.1 白屏问题

可能原因及解决方案：
- **组件导入路径错误**：检查import路径是否正确
- **异步组件未加载完成**：添加loading状态
- **JavaScript运行时错误**：查看浏览器控制台
- **CSS未加载**：检查样式文件引用

### 10.2 卡死问题

可能原因及解决方案：
- **beforeEach守卫未调用next()**：确保所有分支都有next()
- **无限循环重定向**：检查redirectUrl逻辑
- **异步操作阻塞**：添加超时机制

### 10.3 回退问题

可能原因及解决方案：
- **使用了replace而非push**：根据需求选择正确方法
- **History模式服务器配置**：确保服务器支持SPA回退
