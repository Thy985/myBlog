# 个人博客系统整合需求文档

## 1. 产品概览

动态个人博客是一个面向专业人士和企业的高级博客系统，支持丰富的内容创作、管理和展示功能，具备企业级的安全性、可扩展性和性能表现。

### 核心价值

* 提供专业的个人品牌展示平台
* 支持多维度内容管理和分类
* 具备企业级安全保障
* 提供数据分析和用户洞察
* 支持多端响应式访问

## 2. 核心功能

### 2.1 用户管理模块
- **注册登录**：支持邮箱、手机号登录
- **个人资料**：详细的个人信息管理，支持头像、简介、联系方式等
- **权限管理**：基于角色的权限控制
  - **管理员**：拥有所有内容的发布、编辑、删除权限，拥有所有用户的管理权限，拥有系统设置和配置权限，拥有所有数据分析和统计权限
  - **普通用户**：使用系统功能，可管理自己发布的文章、分类标签、媒体库，可浏览所有文章，可对管理员发布的文章进行评论，可对所有文章进行点赞，可查看自己的个人资料和管理自己的账号设置
  - **未登录访客**：仅具备浏览管理员发布的文章和点赞权限，不可访问评论功能，不可管理任何内容
- **安全设置**：密码管理、登录历史

### 2.2 内容管理模块
- **文章管理**：创建、编辑、删除、预览文章
  - **权限控制**：
    - **管理员**：拥有所有文章的管理权限
    - **普通用户**：仅可管理自己发布的文章
- **分类标签**：支持多级分类和标签管理
  - **权限控制**：
    - **管理员**：拥有所有分类标签的管理权限
    - **普通用户**：仅可管理自己创建的分类标签
- **媒体库**：图片、视频、文件上传和管理
  - **权限控制**：
    - **管理员**：拥有所有媒体文件的管理权限
    - **普通用户**：仅可管理自己上传的媒体文件
- **草稿系统**：自动保存、版本历史、恢复功能
- **内容编辑器**：Markdown编辑器，支持代码高亮、公式等

### 2.3 展示模块
- **首页**：个性化推荐、最新文章、热门内容
  - **未登录状态**：仅显示管理员发布的文章
  - **已登录状态**：显示管理员发布的文章和当前登录用户自己发布的文章
- **文章详情**：响应式布局、分享功能
  - **未登录状态**：显示文章内容，支持点赞，不显示评论功能入口
  - **已登录状态**：显示文章内容，支持点赞，对管理员发布的文章提供评论功能
- **分类页面**：按分类浏览内容
  - **未登录状态**：仅显示管理员发布的文章
  - **已登录状态**：显示所有文章
- **标签页面**：按标签聚合内容
  - **未登录状态**：仅显示管理员发布的文章
  - **已登录状态**：显示所有文章
- **归档页面**：按时间线展示历史内容
  - **未登录状态**：仅显示管理员发布的文章
  - **已登录状态**：显示所有文章
- **搜索功能**：全文搜索、高级筛选
  - **未登录状态**：仅搜索管理员发布的文章
  - **已登录状态**：搜索所有文章
- **用户中心**：
  - **未登录状态**：显示用户注册/登录入口
  - **已登录状态**：显示用户个人中心入口，可查看和管理当前登录用户自己发布的文章、分类标签和媒体库

### 2.4 互动模块
- **评论系统**：支持嵌套评论、审核、回复通知
  - **权限控制**：
    - **管理员**：可对所有文章进行评论，可管理所有评论
    - **普通用户**：仅可对管理员发布的文章进行评论
    - **未登录访客**：不可进行任何评论
- **点赞收藏**：内容点赞、收藏功能
  - **权限控制**：支持未登录用户和已登录用户点赞
- **分享功能**：多平台分享、二维码生成

### 2.5 数据分析模块
- **访问统计**：PV、UV、停留时间、来源分析
- **内容分析**：热门文章、阅读趋势、用户偏好
- **用户分析**：用户画像、活跃度、互动情况
- **转化分析**：分享效果
- **权限控制**：
  - **管理员**：拥有所有数据分析和统计权限
  - **普通用户**：无数据分析权限
  - **未登录访客**：无数据分析权限

### 2.6 AI智能体模块
- **智能对话**：支持自然语言交互，理解用户意图
  - **权限控制**：
    - **管理员**：可使用所有AI功能，包括系统级AI配置
    - **普通用户**：可使用AI对话功能，需配置个人API Key
    - **未登录访客**：不可使用AI功能
- **意图识别**：自动识别用户意图类型（聊天、创作、搜索、总结等）
- **多模型支持**：支持OpenAI、Claude、GLM、百度文心、Ollama等多种LLM提供商
- **流式输出**：支持SSE流式响应，提升用户体验
- **记忆管理**：
  - **工作记忆**：当前会话上下文
  - **短期记忆**：最近N轮对话历史
  - **长期记忆**：用户偏好、重要事实持久化存储
- **工具调用**：支持AI调用系统工具完成任务
  - 文章生成、编辑、发布
  - 知识库查询（RAG）
  - 定时任务管理
  - 搜索功能
- **安全过滤**：
  - 输入长度限制
  - 敏感词过滤
  - 提示词注入防护
  - 速率限制（用户级、会话级、全局）
- **RAG检索增强**：基于向量数据库的知识库问答
- **用户级AI配置**：支持用户配置个人API Key和偏好模型

### 2.7 系统管理模块
- **站点设置**：基本信息、SEO配置、主题设置
- **插件管理**：功能扩展、第三方集成
- **数据备份**：自动备份、手动备份、恢复功能
- **日志管理**：操作日志、访问日志、错误日志
- **AI系统配置**：管理全局AI设置、默认模型、系统级API Key
- **权限控制**：
  - **管理员**：拥有所有系统管理权限
  - **普通用户**：无系统管理权限
  - **未登录访客**：无系统管理权限

## 4. 权限管理

### 4.1 系统角色定义

#### 4.1.1 管理员
- **角色描述**：系统的最高权限拥有者，负责系统的整体管理和维护
- **权限范围**：
  - 拥有所有内容的发布、编辑、删除权限
  - 拥有所有用户的管理权限
  - 拥有系统设置和配置权限
  - 拥有所有数据分析和统计权限

#### 4.1.2 普通用户
- **角色描述**：通过注册登录系统的用户
- **权限范围**：
  - 可管理自己发布的文章、分类标签、媒体库
  - 可浏览所有文章（包括管理员和其他用户发布的）
  - 可对管理员发布的文章进行评论
  - 可对所有文章进行点赞
  - 可查看自己的个人资料和管理自己的账号设置

#### 4.1.3 未登录访客
- **角色描述**：未注册或未登录系统的用户
- **权限范围**：
  - 仅可浏览管理员发布的文章
  - 仅可对文章进行点赞
  - 不可访问评论功能
  - 不可管理任何内容

### 4.3 权限控制机制

#### 4.3.1 前端权限控制
- **登录状态识别**：基于JWT的身份验证机制，通过token识别用户登录状态
- **UI元素显示控制**：根据用户登录状态和角色，动态控制UI元素的显示和隐藏
- **功能入口控制**：未登录用户点击需要权限的功能时，重定向到登录页面
- **状态同步**：确保前端UI展示与用户权限状态实时同步

#### 4.3.2 后端权限验证
- **API权限验证**：所有需要权限的API接口都进行权限验证
- **数据访问控制**：确保用户只能访问和修改自己有权限的数据
- **操作权限检查**：在执行关键操作前，检查用户是否具有相应的操作权限
- **防止越权访问**：通过后端验证，防止用户通过直接调用API等方式越权访问

#### 4.3.3 权限验证流程
1. **用户请求**：用户发起功能请求
2. **登录状态检查**：检查用户是否登录
3. **角色识别**：识别用户的角色（管理员/普通用户）
4. **权限验证**：验证用户是否具有执行该操作的权限
5. **操作执行**：验证通过后执行操作，否则返回权限错误

### 4.4 内容权限管理

#### 4.4.1 文章权限
- **管理员**：可创建、编辑、删除所有文章
- **普通用户**：仅可创建、编辑、删除自己发布的文章
- **未登录访客**：不可创建、编辑、删除任何文章

#### 4.4.2 分类标签权限
- **管理员**：可创建、编辑、删除所有分类标签
- **普通用户**：仅可创建、编辑、删除自己创建的分类标签
- **未登录访客**：不可创建、编辑、删除任何分类标签

#### 4.4.3 媒体库权限
- **管理员**：可上传、管理所有媒体文件
- **普通用户**：仅可上传、管理自己上传的媒体文件
- **未登录访客**：不可上传、管理任何媒体文件

#### 4.4.4 评论权限
- **管理员**：可对所有文章进行评论，可管理所有评论
- **普通用户**：仅可对管理员发布的文章进行评论
- **未登录访客**：不可进行任何评论

#### 4.4.5 AI智能体权限
- **管理员**：
  - 可使用所有AI功能
  - 可使用系统默认API Key进行对话
  - 可使用AI文章生成和改写功能
  - 可管理知识库（索引文章、重建向量库）
  - 可配置系统级AI设置
- **普通用户**：
  - 可使用AI对话功能（需配置个人API Key）
  - 可查看可用模型列表
  - 可配置个人AI设置（API Key、偏好模型）
  - 不可使用系统级AI管理功能
- **未登录访客**：
  - 不可使用任何AI功能
  - 不可访问AI相关接口

### 4.5 权限管理最佳实践

#### 4.5.1 前端实现建议
- 使用路由守卫（Route Guard）控制页面访问权限
- 使用条件渲染控制UI元素的显示和隐藏
- 统一管理用户权限状态，确保状态一致性
- 对需要权限的操作进行前端验证，提升用户体验

#### 4.5.2 后端实现建议
- 使用中间件（Middleware）统一处理权限验证
- 实现细粒度的权限控制，确保最小权限原则
- 对所有API接口进行权限验证，防止越权访问
- 记录权限相关的操作日志，便于审计和排查问题

#### 4.5.3 安全建议
- 使用HTTPS协议保护数据传输
- 对敏感操作进行二次验证
- 定期更新和强化权限控制机制
- 防止SQL注入、XSS等攻击，保护系统安全

## 13. AI智能体模块详细需求

### 13.1 架构设计

#### 13.1.1 核心组件架构

```
┌─────────────────────────────────────────────────────────────┐
│                        AI Gateway                           │
│                   (统一入口/限流/路由)                        │
└──────────────────────┬──────────────────────────────────────┘
                       │
┌──────────────────────▼──────────────────────────────────────┐
│                  Agent Orchestrator                         │
│              (意图识别/计划编排/执行调度)                      │
└──────────────────────┬──────────────────────────────────────┘
                       │
       ┌───────────────┼───────────────┐
       │               │               │
┌──────▼──────┐ ┌──────▼──────┐ ┌──────▼──────┐
│   Intent    │ │   Memory    │ │    Tool     │
│  Classifier │ │   Manager   │ │   Registry  │
└─────────────┘ └─────────────┘ └─────────────┘
       │               │               │
       └───────────────┼───────────────┘
                       │
┌──────────────────────▼──────────────────────────────────────┐
│                   LLM Provider Manager                        │
│         (多模型支持/用户级配置/负载均衡)                        │
└─────────────────────────────────────────────────────────────┘
```

#### 13.1.2 数据流架构

1. **请求入口**：AIGateway接收所有AI请求，进行限流和基础校验
2. **意图识别**：IntentClassifier分析用户输入，识别意图类型和置信度
3. **记忆加载**：MemoryManager根据意图需求加载相关记忆上下文
4. **计划编排**：AgentOrchestrator构建执行计划，确定执行步骤
5. **工具调用**：如需工具，AIToolRegistry执行相应工具
6. **LLM调用**：UserLLMProviderManager选择合适的LLM提供商生成响应
7. **记忆保存**：异步保存对话记录到记忆系统
