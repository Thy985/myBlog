# Apifox 测试环境配置说明

## 验证码处理

### 方案一：测试环境禁用验证码（推荐）

**配置步骤**:

1. 确保后端使用测试环境配置（`application-dev.yaml` 或 `application-test.yaml`）
2. 配置文件中 `captcha.enabled=false`
3. 在 Apifox 中使用固定验证码 `1234`

**Apifox 环境变量配置**:
```json
{
  "test_captcha": "1234"
}
```

**测试用例示例**:
```json
{
  "username": "admin",
  "password": "Admin123",
  "captcha": "{{test_captcha}}",
  "captchaKey": "test-key"
}
```

### 方案二：使用真实验证码（生产环境）

**前置脚本**:
```javascript
// 1. 先调用获取验证码接口
pm.sendRequest({
    url: pm.environment.get("base_url") + "/captcha/get",
    method: "GET"
}, function (err, response) {
    if (!err && response.code === 200) {
        var jsonData = response.json();
        // 保存验证码 Key
        pm.environment.set("captcha_key", jsonData.data.key);
        // 如果有验证码内容（测试环境），保存验证码
        if (jsonData.data.captcha) {
            pm.environment.set("captcha_value", jsonData.data.captcha);
        }
    }
});
```

**请求体**:
```json
{
  "username": "admin",
  "password": "Admin123",
  "captcha": "{{captcha_value}}",
  "captchaKey": "{{captcha_key}}"
}
```

## 测试用例编写

### 登录接口测试（测试环境）

```javascript
// Pre-request Script
// 测试环境使用固定验证码
pm.environment.set("current_captcha", pm.environment.get("test_captcha"));

// Request Body
{
  "username": "admin",
  "password": "Admin123",
  "captcha": "{{current_captcha}}",
  "captchaKey": "test-key-{{$timestamp}}"
}

// Tests
pm.test("登录成功", function () {
    var jsonData = pm.response.json();
    pm.expect(jsonData.success).to.be.true;
    
    // 保存 Token
    if (jsonData.data && jsonData.data.token) {
        pm.environment.set("access_token", jsonData.data.token);
    }
});
```

### 登录接口测试（生产环境）

```javascript
// Pre-request Script
// 生产环境需要先获取验证码
if (pm.environment.get("captcha_enabled") === "true") {
    pm.sendRequest({
        url: pm.environment.get("base_url") + "/captcha/get",
        method: "GET"
    }, function (err, response) {
        if (!err) {
            var jsonData = response.json();
            pm.environment.set("captcha_key", jsonData.data.key);
            // 注意：生产环境无法自动获取验证码内容
            // 需要手动输入或使用 OCR 识别
        }
    });
}

// Request Body
{
  "username": "admin",
  "password": "Admin123",
  "captcha": "手动输入或OCR识别",
  "captchaKey": "{{captcha_key}}"
}
```

## 常见问题

### Q1: 测试环境验证码验证失败

**原因**: 后端配置未禁用验证码

**解决**:
1. 检查 `application-dev.yaml` 中 `captcha.enabled` 是否为 `false`
2. 检查环境变量 `CAPTCHA_ENABLED` 是否设置
3. 重启应用

### Q2: 生产环境如何测试

**方案一**: 使用手动测试
- 在 Apifox 中手动输入验证码

**方案二**: 使用 OCR 识别
- 参考文档中的 OCR 方案

**方案三**: 使用获取验证码接口
- 仅在测试环境暴露验证码内容

### Q3: 如何切换环境

在 Apifox 中：
1. 点击右上角环境选择器
2. 选择对应环境（本地/测试/生产）
3. 环境变量自动切换

## 最佳实践

### 1. 环境隔离

- ✅ 开发环境：禁用验证码
- ✅ 测试环境：禁用验证码或使用固定验证码
- ✅ 生产环境：启用验证码

### 2. 自动化测试

- ✅ 使用测试环境进行自动化测试
- ✅ 配置 `captcha.enabled=false`
- ✅ 使用固定验证码 `1234`

### 3. 手动测试

- ✅ 生产环境手动输入验证码
- ✅ 或使用 OCR 识别工具

### 4. 安全性

- ⚠️ 确保生产环境验证码始终启用
- ⚠️ 测试环境验证码接口不要暴露到公网
- ⚠️ 定期更换测试环境固定验证码
