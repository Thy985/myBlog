## Design Context

### Users
- **Primary**: Developers and tech community members
- **Context**: Desktop work hours - users read/write blog content at their desks during work/study sessions
- **Job to be done**: Consume technical blog content, manage their own articles, and interact with an AI agent for content operations

### Brand Personality
- Technical and professional, but not cold/corporate
- Clean and focused - respects developer time and attention
- Forward-thinking - embraces AI for content growth automation

### Aesthetic Direction
- **Visual tone**: Modern developer-tool aesthetic (Linear, Raycast, Vercel inspired)
- **Theme**: Light mode primary (desktop context), dark mode available
- **Key differentiator**: AI-first design with agent UI that feels like a natural extension of the blog

### Design Principles
1. **Content-first**: Article content and readability take priority over decorative elements
2. **Developer-friendly**: Clean code snippets, monospace accents, technical precision
3. **AI as collaborator**: Agent UI should feel powerful but not intimidating
4. **Performance-conscious**: Fast load times, minimal jank - respects developer patience
