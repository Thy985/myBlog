# 前端项目架构设计文档

## 1. 项目概述

### 1.1 项目简介
XingChen博客前端是一个基于Vue 3 + Vite开发的现代化博客前端系统，包含前台和管理后台两个部分，功能完整，结构清晰。

### 1.2 技术栈
- **框架**：Vue 3
- **构建工具**：Vite
- **UI组件库**：Element Plus
- **CSS框架**：Tailwind CSS
- **状态管理**：Pinia
- **路由管理**：Vue Router
- **HTTP客户端**：Axios
- **测试框架**：Vitest
- **XSS防护**：DOMPurify

## 2. 目录结构

```
src/
├── api/                # API请求模块
│   ├── admin/          # 后台API
│   └── frontend/       # 前台API
├── assets/             # 静态资源
├── components/         # 通用组件
├── composables/        # 组合式函数
├── constants/          # 常量定义
├── layouts/            # 布局组件
├── plugins/            # 插件
├── router/             # 路由配置
├── stores/             # 状态管理
├── types/              # 类型定义
├── utils/              # 工具函数
├── views/              # 页面组件
├── App.vue             # 根组件
├── axios.js            # Axios配置
├── main.js             # 入口文件
└── permission.js       # 权限管理
```

### 2.1 目录说明

| 目录 | 职责 |
| ---- | ---- |
| api/ | 封装所有API请求，按前台和后台分类 |
| assets/ | 存放静态资源，如图片、CSS文件等 |
| components/ | 存放通用组件，如ArticleCard、Pagination等 |
| composables/ | 存放Vue 3组合式函数，如api.js、auth.js等 |
| constants/ | 存放常量定义，如API地址、路由路径等 |
| layouts/ | 存放布局组件，如admin.vue、Header.vue、Footer.vue等 |
| plugins/ | 存放插件配置，如Element Plus、viewer等 |
| router/ | 存放路由配置，定义应用的路由结构 |
| stores/ | 存放Pinia状态管理，管理应用的全局状态 |
| types/ | 存放TypeScript类型定义 |
| utils/ | 存放工具函数，如loading.js、notification.js等 |
| views/ | 存放页面组件，按前台和后台分类 |

## 3. 核心功能模块

### 3.1 认证模块
- **功能**：用户登录、注册、密码重置、MFA验证
- **实现**：使用JWT令牌进行身份验证，支持Token自动刷新
- **安全**：实现了CSRF令牌验证，Cookie安全属性配置

### 3.2 文章模块
- **功能**：文章列表、文章详情、文章发布、文章编辑
- **实现**：使用组件化设计，支持Markdown编辑器
- **优化**：实现了文章缓存，提升加载速度

### 3.3 分类与标签模块
- **功能**：分类管理、标签管理、分类文章列表、标签文章列表
- **实现**：使用Tree组件展示分类层级，支持拖拽排序

### 3.4 评论模块
- **功能**：文章评论、评论管理、评论回复
- **实现**：支持嵌套评论，实时更新评论数

### 3.5 媒体管理模块
- **功能**：文件上传、文件管理、图片预览
- **实现**：支持多文件上传，图片懒加载

### 3.6 数据分析模块
- **功能**：访问统计、文章分析、用户分析
- **实现**：使用ECharts绘制数据图表

## 4. 数据流设计

### 4.1 全局状态管理
- **状态管理**：使用Pinia进行状态管理
- **模块划分**：按功能模块划分store，如user、article、category等
- **数据流**：组件 → actions → mutations → state → 组件

### 4.2 API请求流程
- **请求封装**：使用composables/api.js封装通用请求逻辑
- **请求拦截**：添加请求拦截器，统一处理认证令牌
- **响应拦截**：添加响应拦截器，统一处理错误和Token刷新
- **缓存策略**：实现了API请求缓存，减少重复请求

### 4.3 路由守卫
- **全局守卫**：实现了全局路由守卫，处理权限验证
- **路由元信息**：使用路由元信息定义页面权限
- **权限控制**：基于角色的权限控制，如admin、user等

## 5. 性能优化

### 5.1 构建优化
- **代码分割**：配置了代码分割，减少首屏加载时间
- **代码压缩**：使用terser进行代码压缩，减小打包体积
- **资源优化**：配置了图片压缩，优化资源加载

### 5.2 运行时优化
- **组件懒加载**：使用路由懒加载和动态导入，减少初始加载时间
- **图片懒加载**：实现了图片懒加载，提升页面加载速度
- **API缓存**：实现了API请求缓存，减少重复请求
- **虚拟滚动**：对长列表使用虚拟滚动，提升渲染性能

### 5.3 性能监控
- **监控工具**：实现了性能监控工具，监控页面加载速度和API响应时间
- **性能指标**：监控首屏加载时间、DOM就绪时间、首次绘制时间等

## 6. 安全设计

### 6.1 XSS防护
- **实现**：使用DOMPurify处理HTML内容，防止XSS攻击
- **指令**：创建了v-sanitize指令，安全处理v-html内容

### 6.2 CSRF防护
- **实现**：添加CSRF令牌验证，在请求头中添加X-CSRF-Token
- **令牌管理**：实现了CSRF令牌的获取、设置和清除功能

### 6.3 认证安全
- **令牌存储**：使用Cookie存储认证令牌，配置了HttpOnly、Secure、SameSite等安全属性
- **Token刷新**：实现了Token自动刷新机制，提升用户体验

### 6.4 数据安全
- **敏感数据**：敏感数据传输使用HTTPS加密
- **输入验证**：前端实现了基本的输入验证，后端进行最终验证
